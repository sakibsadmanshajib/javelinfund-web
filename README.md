# Javelin Fund

Static website for **Javelin Fund** — registered Canadian charity (BN 755722097 RR0001) delivering direct relief and long-term programs to families in Northern Haiti since 2016.

## Stack (planned)

- **Astro** static site generator
- **Decap CMS** for non-tech content editing (git-based)
- **Cloudflare Pages** hosting + custom domain `javelinfund.ca`
- **CanadaHelps** primary donation rail (auto-issues CRA tax receipts)
- **Interac e-Transfer** Canadian fallback
- **Google Apps Script webhook → Google Sheets** for contact / volunteer / newsletter forms

## Design

- **Direction:** Bold Activist — Haitian Flag palette
- **Palette:** Navy `#0a1a3f` · Red `#d62828` · Gold `#ffd60a` · Ivory `#fafaf7`
- **Type:** Archivo Black (display) + Playfair Display italic (accent) + Inter (body)
- **Imagery:** real Javelin Fund photos only — no stock
